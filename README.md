# 俺のランチ 〜押忍！ランチ番長〜 🍱💢

好きなランチを記録して、会社の仲間や友達と共有・記録するためのモバイルWebアプリ。
記録を重ねるとレベルアップして「ランチ番長」へと昇格していく。
イラストの世界観は **押忍！番長！** 風（黒×金×赤の極太デザイン）。

## 使い方の流れ

1. **GOボタンでお店を記録** — ランチに入る前にホームの「GO」を押すと、位置情報から近くのお店候補が出る。選ぶと日時とともに記録が始まる。
2. **食べたものを記録** — 食べる前に写真を1枚。撮れない時は食べたものを入力すると「イメージ図」（絵文字）が自動生成される。
3. **5つ星で評価** — 食べ終わったら星で評価。
4. **一言コメントして保存** — 仲間への伝言を添えて記録完了。
5. **マイマップ** — 記録したお店は自分だけのランチMAPに自動でピン留め。
6. **共有 & 称号** — 記録や戦績を仲間に共有。件数が増えるとレベルアップして称号を獲得。目指せ「伝説のランチ番長」！

## 主な機能

| 機能 | 内容 |
| --- | --- |
| お店検索 | OpenStreetMap の Overpass API で現在地周辺の飲食店を検索（APIキー不要）。手入力にも対応 |
| 写真 / イメージ図 | カメラ撮影、または食べたもの名から絵文字のイメージ図を生成 |
| 5つ星評価 & コメント | ランチごとに評価と一言を記録 |
| ランチMAP | Leaflet + OpenStreetMap で記録店を地図表示（Googleマップ的なお気に入りマップ） |
| ゲーミフィケーション | 記録数に応じてレベルアップ、8段階の番長称号、レベルアップ演出 |
| 共有 | Web Share API（非対応端末はクリップボードコピー） |
| ログイン | Googleアカウント連携（デモはモック。本番は GIS に差し替え可能） |

## 技術スタック

- React 18 + TypeScript + Vite
- Leaflet / react-leaflet（地図、APIキー不要のOSMタイル）
- OpenStreetMap Overpass API（近隣店舗検索）
- localStorage によるデータ永続化（バックエンド差し替え前提）

## 開発

```bash
npm install      # 依存をインストール
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果をプレビュー
npm run lint     # 型チェック
```

スマホでの利用を想定したモバイルファースト設計。位置情報・カメラを使うため、
実機では **HTTPS（または localhost）** でアクセスする必要がある。

## 本番運用に向けたメモ

これはフロントエンド主体のデモ実装です。実運用では以下を追加してください。

- **Google ログイン**: `VITE_GOOGLE_CLIENT_ID` を設定し、`src/api/auth.ts` を
  Google Identity Services の本物のフローに差し替え。
- **データ共有 / 同期**: 現状はブラウザの localStorage に保存。Firebase / Supabase 等の
  バックエンドに `src/storage.ts` を差し替えると、友達との共有や複数端末同期が可能。
- **Googleマップ表示**: 記録した座標をユーザーの Google マイマップへエクスポートする連携を追加可能。
